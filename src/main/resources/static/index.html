spring_batch_practical_cases

머리말

1부. 시작하기 — 배치와 프로젝트 골격

1장. Spring Batch는 언제 쓰는가 — 배치 작업의 정의, 적합/부적합 판단 기준, 10가지 사례 지도

2장. 개발 환경과 프로젝트 준비 — Maven·Spring Boot·MySQL·Lombok 설정, `application.properties`, 메타테이블 초기화

3장. Spring Batch 핵심 구조 — Job·Step·Chunk, Reader→Processor→Writer, JobRepository와 메타테이블

4장. 운영 관리자 화면 만들기 — Thymeleaf + Tailwind(CDN) + Spring Security로 배치 실행·이력 조회 대시보드 구축

2부. 파일과 데이터 입출력 사례

5장. 상품 CSV 대량 업로드 — FlatFileItemReader, Validation 검증, JdbcBatchItemWriter, 실패 행 리포트

6장. DB 마이그레이션과 데이터 보정 — JdbcPagingItemReader로 구간 분할, 변경 전 백업·검증·반영

3부. 정산과 집계 사례

7장. 매일 새벽 정산 배치 — 멱등성 설계, settlement 테이블, 중복 정산 방지(UNIQUE)

8장. 통계·리포트 집계 — 기준일 JobParameter, 집계 테이블, 대시보드 연동

4부. 회원·알림·후처리 사례

9장. 휴면 회원 전환 — 상태 변경 Step과 알림 대상 생성 Step 분리

10장. 알림 발송 대상 생성 — 수신 동의·중복 발송 방지, notification_target 테이블

11장. 로그·이벤트 데이터 후처리 — 원본 보존, 요약·집계 테이블 생성

12장. 만료·삭제·아카이빙 — Chunk 단위 삭제로 DB 부하 분산, 아카이브 이관

5부. 외부 연동·확장·운영

13장. 외부 API 연동 데이터 수집 — Custom Reader, Retry 정책, 중복 저장 방지

14장. 검색 인덱스 동기화 — Custom Writer, 전체 재색인 vs 증분 색인

15장. Skip·Retry와 트랜잭션 설계 — Chunk 내 Retry/Skip/Recover, 정책 결정 기준

16장. 성능 확장: 멀티스레드·파티셔닝 — 단일 스레드 측정 후 확장하기

17장. 운영: 스케줄링·재시작·모니터링 — `@Scheduled` 연동, 재시작, 실행 이력 추적, 알림
