부록 B. Reader/Writer 구성 조합 치트시트

사례 대부분은 입력원과 출력처를 갈아 끼우는 것으로 만들어집니다. 자주 쓰는 조합을 정리합니다. (처음 다룬 장은 각 항목에 표기)

흐름별 조합

파일 → DB (5장)

FlatFileItemReader   (CSV/고정폭 텍스트 읽기)
 → ItemProcessor      (검증·변환)
 → JdbcBatchItemWriter (대량 INSERT)

사용 사례: CSV 상품 등록, 엑셀 회원 업로드, 거래처 목록 등록

DB → DB (6·7·8장)

JdbcPagingItemReader  (페이지 단위로 안전하게 읽기)
 → ItemProcessor
 → JdbcBatchItemWriter

사용 사례: 정산, 통계 집계, 데이터 보정, 마이그레이션

DB → API/검색엔진 (14장)

JdbcPagingItemReader
 → ItemProcessor       (검색 문서로 변환)
 → Custom ItemWriter   (bulk API 전송)

사용 사례: 검색 엔진 색인, 외부 CRM 동기화, 알림 시스템 전달

API → DB (13장)

Custom ItemReader     (외부 API 호출, read()가 null이면 종료)
 → ItemProcessor
 → JpaItemWriter / JdbcBatchItemWriter

사용 사례: 배송 상태 수집, 환율 정보 수집, 공공데이터 수집

주요 Reader

Reader용도메모
FlatFileItemReaderCSV·텍스트 파일linesToSkip로 헤더 처리, @StepScope로 파일 경로 주입
JdbcPagingItemReader대량 DB 조회유니크 정렬 키 필수, pageSize 지정
JdbcCursorItemReaderDB 커서 조회단일 커넥션 유지, 멀티스레드엔 부적합
JpaPagingItemReaderJPA 기반 페이징영속성 컨텍스트 주의
Custom ItemReaderAPI 등 비표준 입력read()가 null이면 읽기 종료

주요 Writer

Writer용도메모
JdbcBatchItemWriter대량 INSERT/UPDATE배치 SQL, 빠름
JpaItemWriterJPA 엔티티 저장영속성 컨텍스트로 flush
FlatFileItemWriter파일 출력리포트·내보내기
Custom ItemWriterAPI·검색엔진 전송write(Chunk<T>)로 묶음 받아 bulk 전송

핵심 빌더 골격 (Spring Batch 5)

// Step
new StepBuilder("name", jobRepository)
    .<In, Out>chunk(500, transactionManager)
    .reader(reader()).processor(processor()).writer(writer())
    .faultTolerant().retry(...).retryLimit(3).skip(...).skipLimit(100)
    .build();

// Job
new JobBuilder("name", jobRepository)
    .start(step1()).next(step2())
    .build();

💡 @StepScope + @Value("#{jobParameters['key']}") 조합으로 파일 경로·기준일 등 실행마다 달라지는 입력을 주입합니다(5·7·8장).
